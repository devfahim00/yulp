# Yulp

Modern, lightweight Android browser. Package: `com.devfahim00.yulp`

Kotlin + WebView + Material 3 (no Compose, small APK). minSdk 29.

## Features
Multi-tab, incognito tabs, smart URL/search bar, progress bar, bookmarks, history, downloads (DownloadManager),
find in page, desktop site mode, web dark mode, long-press link/image actions, fullscreen video, file upload,
external app links (intent://, mailto:, tel:), share, clear browsing data, light/dark theme, can be set as default browser.

## Build
Open in Android Studio, or push to GitHub: the `Build APK` workflow produces a release APK artifact.
